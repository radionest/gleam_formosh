# Guides

How to use Formosh. Read top to bottom if you're new; jump in if you're not.

* [Quickstart](quickstart.md) — install and render a form in five minutes.
* [Configuration](configuration.md) — the `FormConfig` builder: submission modes, error visibility, readonly fields, initial values, UiSchema, cross-field validation.
* [Web Component](web-component.md) — `<formosh-form>` as a custom element, with attributes and events. No Gleam required.
* [Styling](styling.md) — Shadow DOM, `::part()`, `data-*` attributes, and adopted parent stylesheets.

Once the form is on the page, the [Reference](../reference/index.md) section
is where to look up specific API signatures and schema support.
