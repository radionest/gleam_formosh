# Как запустить примеры Formosh

## Структура примеров

```
formosh/
├── src/example/         # Исполняемые демо-файлы
│   ├── demo_contact.gleam      # Контактная форма
│   ├── demo_registration.gleam # Форма регистрации
│   └── demo_survey.gleam       # Опрос клиентов
└── example/
    ├── schemas/         # JSON схемы
    │   ├── contact_form.json
    │   ├── user_registration.json
    │   └── survey_form.json
    └── index.html       # HTML страница

```

## Запуск примеров

### 1. Контактная форма
```bash
gleam run -m lustre/dev start --entry=example/demo_contact --port=3000
```
Откройте: http://localhost:3000

### 2. Форма регистрации
```bash
gleam run -m lustre/dev start --entry=example/demo_registration --port=3000
```
Откройте: http://localhost:3000

### 3. Опрос клиентов
```bash
gleam run -m lustre/dev start --entry=example/demo_survey --port=3000
```
Откройте: http://localhost:3000

## Что вы увидите

После запуска любого примера:
1. В консоли появится сообщение "Listening on http://127.0.0.1:3000"
2. Откройте браузер на указанном адресе
3. Вы увидите работающую форму с валидацией

## Особенности каждого примера

### Контактная форма
- 6 полей включая email и телефон
- Валидация формата email
- Выпадающий список для темы
- Текстовое поле для сообщения

### Форма регистрации  
- Вложенные секции (личные данные, аккаунт, адрес)
- Валидация паролей
- Выбор страны и пола
- Чекбоксы согласий

### Опрос клиентов
- Рейтинговые шкалы 1-5 и 1-10
- Множественный выбор
- Текстовые поля для отзывов
- Вопросы о будущем взаимодействии

## Остановка сервера

Нажмите `Ctrl+C` в терминале где запущен сервер.

## Проблемы и решения

### Порт уже занят
Используйте другой порт:
```bash
gleam run -m lustre/dev start --entry=example/demo_contact --port=4000
```

### Не компилируется
Убедитесь что вы в корневой директории проекта и выполните:
```bash
gleam deps download
gleam build
```

### Форма не отображается
1. Проверьте консоль браузера на ошибки
2. Убедитесь что сервер запущен (должно быть "Listening on...")
3. Попробуйте обновить страницу (F5)
